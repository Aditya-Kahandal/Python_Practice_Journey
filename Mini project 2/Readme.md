# Text Analyzer (Python CLI Project)

## Overview

Text Analyzer is a simple command-line Python application that performs common text-processing operations on user input.

This project was built to practice:

* Functions
* Loops
* Conditional statements
* Dictionaries
* String manipulation
* Menu-driven programs

## Features

1. Count Vowels
2. Reverse Text
3. Check Palindrome
4. Character Frequency Counter
5. Exit Program

## Concepts Used

* String Traversal
* Dictionary Operations
* Frequency Counting
* Two-Pointer Logic (Palindrome Check)
* Function Design
* CLI (Command Line Interface)

## Sample Usage

Enter the word you want to perform operations on:

hello

Which operation would you like to perform?

1. Count vowels
2. Reverse text
3. Check palindrome
4. Character frequency
5. Exit

Output Examples:

Count Vowels:
2

Reverse Text:
olleh

Palindrome Check:
False

Character Frequency:
{'h': 1, 'e': 1, 'l': 2, 'o': 1}
