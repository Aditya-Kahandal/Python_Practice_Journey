# CLI Contact Book

A simple command-line contact management system built in Python.

## Features
- Add Contact
- Search Contact
- Display Contacts
- Delete Contact

## Handled Exceptional User Scenarioss
- Invalid Menu Choice
- Empty String Input by User
- User Oriented Output
- Better Output presentation
- Duplicate Prevention 

## Concepts Used
- Dictionaries
- Functions
- Loops
- Match-case
- State Management
- try-except method

## Learning Outcome
Built my first stateful CLI-based mini system in Python.
